# Agentic Marketing Connectors

Public release monorepo for Patronage's agentic marketing connector packages.

## Packages

| Package | Path | Description |
| --- | --- | --- |
| `@patronage/ads-sync` | `packages/ads-sync` | Composable Ads Sync ingestion primitives for Cloudflare-hosted ad platform data pipelines. |
| `@patronage/cli` | `packages/cli` | Minimal local CLI harness for Patronage Open Source Core |
| `@patronage/connector-lifecycle` | `packages/connector-lifecycle` | Provider-neutral guarded mutation lifecycle contracts |
| `@patronage/google-ads` | `packages/google-ads` | Worker-safe Google Ads primitives for Patronage Core |
| `@patronage/linkedin-ads` | `packages/linkedin-ads` | Worker-safe LinkedIn Ads reporting and guarded mutation primitives for Patronage Core |
| `@patronage/meta-ads` | `packages/meta-ads` | Worker-safe Meta Ads reporting and guarded mutation primitives for Patronage Core |
| `@patronage/meta-social` | `packages/meta-social` | Worker-safe Meta organic social Graph API primitives for Patronage Core |
| `@patronage/reddit-ads` | `packages/reddit-ads` | Worker-safe Reddit Ads primitives for Patronage Core |
| `@patronage/tiktok-ads` | `packages/tiktok-ads` | Worker-safe TikTok Ads primitives for Patronage Core |
| `@patronage/x-posts` | `packages/x-posts` | Worker-safe X authored post ingestion primitives for Patronage Core |

## Status

These packages are open-source building blocks for agentic marketing tools and Cloudflare-hosted automation.
